## DevFolio: personal developer portfolio

**Repository URL:** https://github.com/varuntejasankineni-coder/devfolio
**Live URL:** https://varuntejasankineni-coder.github.io/devfolio/

A responsive, single-page portfolio built with semantic HTML, CSS variables, Flexbox and CSS Grid, deployed on GitHub Pages.

### Build checklist

- [x] `<header>`, `<main>`, `<footer>` + `<section>`s for about and projects
- [x] `<title>` and viewport meta tag in `<head>`
- [x] Colour + type system applied consistently
- [x] Flexbox used for at least one row
- [x] CSS Grid used for the projects section
- [x] At least one `@media (min-width: …)` breakpoint that changes the layout
- [x] Images use `max-width: 100%` (nothing overflows on mobile)
- [x] Real content: name, bio, ≥2 project cards, contact links
- [x] README.md with a live link
- [ ] Deployed on GitHub Pages and the live URL loads
